# A3 Sistema Web Anti Golpes - 26.1

Sistema web para a consulta de números suspeitos, registro de denúncias e visualização de indicadores de risco associados a golpes telefônicos.

# Tecnologias Utilizadas
- **Backend:** Node.js + Express.js
- **Banco de Dados:** MySQL
- **Frontend:** React
- **Arquitetura:** Monólito Modular

# Objetivos Funcionais da V1
- Permitir consulta pública de números telefônicos com exibição de score de risco.
- Registrar denúncias de golpes detalhadas.
- Calcular score de reputação dinâmico (Baixo, Médio e Alto risco).
- Detectar padrões suspeitos de atividade (picos de denúncias, campanhas de fraude).
- Exibir dashboard analítico com estatísticas e tendências.
- Painel de Admin para gerenciamento interno.
